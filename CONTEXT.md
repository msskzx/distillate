# Distillate

Distillate is where an owner keeps what agents learned while working on the owner's projects, written up so a reader can learn it too.

## Language

### Content

**Lesson**:
A long-form page that teaches one idea, drawn from real work or from study, with prose and any visuals the idea needs.
_Avoid_: Article, tutorial, post

**Record**:
A short note of one instructive event during work: what happened, the evidence for it, and the check that would have caught it.
_Avoid_: Learning record, card, log entry

**Track**:
An ordered series of lessons that share one mission, such as `text-to-evidence`, `ai-agents` or `world-models`.
_Avoid_: Course, curriculum, category

**Mission**:
The reason a track exists: what its reader wants to be able to do after it.
_Avoid_: Goal, objective

**Source project**:
The project whose work a lesson or record was drawn from.
_Avoid_: Repo, origin

### Disclosure

**Disclosure**:
How much of the source project a lesson or record may reveal. Either open or generic.
_Avoid_: Visibility, privacy, public/private

**Open**:
The disclosure of an item whose source project is public, so it may name files, pull requests, figures and code.
_Avoid_: Public, detailed

**Generic**:
The disclosure of an item whose source project is proprietary, so it tells the problem and the idea of the solution, the way a candidate describes past work in an interview, without names, paths, code or figures that identify the project.
_Avoid_: Private, redacted, anonymised

### Paused

**Card**:
A short structured capture of a solved challenge that an agent submitted for the owner to review. Paused: no card is captured or shown until cards return on a remote database.
_Avoid_: Record (a record is a page, a card is a database row)
