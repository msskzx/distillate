# Distillate

Distillate is where an owner keeps what agents learned while working on the owner's projects, written up so a reader can learn it too.

## Language

### Content

**Lesson**:
A long-form page that teaches one idea, drawn from real work or from study, with prose and any visuals the idea needs.
_Avoid_: Article, tutorial, post

**Record**:
One piece of experience from work, written when it happens so an agent can find it before repeating it: a challenge, an obstacle or a detour, with its outcome, the conditions it held under and its evidence.
_Avoid_: Learning record, card, log entry, attempt, case

**Track**:
An ordered series of lessons that share one mission, such as `text-to-evidence`, `ai-agents` or `world-models`.
_Avoid_: Course, curriculum, category

**Mission**:
The reason a track exists: what its reader wants to be able to do after it.
_Avoid_: Goal, objective

**Source project**:
The project whose work a lesson or record was drawn from.
_Avoid_: Repo, origin

### Records

**Kind**:
What a record is about. One of challenge, obstacle or detour.

**Challenge**:
The problem a piece of work exists to solve, and how it was approached.
_Avoid_: Task, feature

**Obstacle**:
A constraint discovered while implementing that shaped the solution.
_Avoid_: Blocker, issue

**Detour**:
Something tried that broke and was then fixed, which the final code no longer shows.
_Avoid_: Bug, mistake, false start

**Outcome**:
How a record ended. Solved, failed (a dead end, with its reason), partial (works within known limits) or open (not yet solved).
_Avoid_: Status, result

**Conditions**:
What was true when a record's approach was tried, such as versions, data size or constraints, so a failure is read as "failed under these conditions" rather than as a ban.
_Avoid_: Context, environment

**Topic**:
A term from a short controlled list that groups records about the same problem across projects.
_Avoid_: Tag, category, label

**Builds on**:
A link from a record to an earlier record it continues from.

**Variant of**:
A link from a record to another record about the same problem met elsewhere.

**Implication**:
The rule or skill a record says should change, or none.
_Avoid_: Takeaway, lesson learned

### Disclosure

**Disclosure**:
How much of the source project a lesson or record may reveal. Either open or generic.
_Avoid_: Visibility, privacy, public/private

**Open**:
The disclosure of an item whose source project is public, so it may name files, pull requests, figures and code.
_Avoid_: Public, detailed

**Generic**:
The disclosure of an item whose source project is proprietary, so it tells the problem and the idea of the solution, the way a candidate describes past work in an interview, without names, paths, code or figures that identify the project.
_Avoid_: Private, redacted, anonymised

### Paused

**Card**:
The database form records may take once there are too many for pull requests. Paused: records are files until then.
_Avoid_: Record (a record is the concept; a card would be its stored row)
