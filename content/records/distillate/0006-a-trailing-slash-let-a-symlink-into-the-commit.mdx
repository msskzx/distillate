Worktrees here share the main checkout's packages through a symlink: each worktree's
`node_modules` points at the main checkout's. The repository ignored `node_modules/`. In git's
ignore syntax a trailing slash means "directories only", and a symlink is a file, so
`git add -A` staged it. The commit summary listed `A node_modules`.

The fix was `git rm --cached node_modules` and an ignore rule without the slash, which
matches a file, a symlink or a directory of that name.

**Evidence:** <RepoLink repo="distillate" path=".gitignore" />.

**Implications:** where worktrees symlink shared folders, ignore them without the trailing
slash, and look at what `git add -A` staged before committing.
