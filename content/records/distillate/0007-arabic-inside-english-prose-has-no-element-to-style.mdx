The restyle asked for Arabic set larger than English. Blocks were easy: `ArabicQuote` is a
component and takes its own size. Most Arabic in the lessons is inline, though, inside an English
sentence, such as the lemmas «كلا، إن، لا، ما» in lesson 6. Lessons may not carry `class`,
`className` or `style`, and the words carry no `lang`, so there is no element to give a size.

The size went into the font instead. The serif stack lists EB Garamond first and Amiri second, so
every Arabic glyph falls back to Amiri. A `size-adjust` declaration on Amiri's `@font-face` scales
only those glyphs. `next/font/google` has no option for declarations, so Amiri's Arabic subset is
self-hosted under `app/fonts/` with its licence and loaded through `next/font/local`, which does.
The first value, 122%, still read smaller than the English beside it in a screenshot; 140% matched.

**Evidence:** <RepoLink repo="distillate" path="app/fonts.ts" /> and the `--font-serif` token in
<RepoLink repo="distillate" path="app/globals.css" />.

**Implications:** when one script appears inline in another's prose and the content cannot carry
markup, scale it with the face's `size-adjust` and check the result in a screenshot rather than by
the number.
