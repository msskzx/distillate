The visual pilot used an animation variable as a duration. Current main had introduced pause-aware JavaScript playback and used that name for numeric progress. Carrying both implementations forward would have mixed time and fraction values under one name.

The integration keeps the existing playback loop. Straight segments receive its fraction as a clipping variable; curved paths receive one minus that fraction as their normalized stroke offset. Pause freezes the same loop, and stop clears the inline drawing state.

**Evidence:** [Namaq PR #520](https://github.com/msskzx/namaq/pull/520), <RepoLink repo="namaq" path="src/app/quran/branches/Grow.tsx" /> and <RepoLink repo="namaq" path="src/app/quran/branches/Grow.test.tsx" />.

**Implications:** integrating current main before edits exposes changed runtime contracts while the local change is still small. Read the consumers of a variable before preserving its name.
