Planning with World Models

Core insight: Predict candidate futures, score them, act briefly in reality, then update from what actually happened.

Three uses

  • Model-predictive control: optimize a short sequence, execute its first action, and re-plan.
  • Tree search: branch over actions and back up predicted values, as in MuZero.
  • Latent actor-critic: learn policy and value from imagined trajectories, as in Dreamer.

Why re-plan?

Long open-loop plans trust too many predictions. Feedback lets reality correct model error before the next action.

Failure mode

An optimizer can exploit blind spots in the model and hallucinate reward. Short horizons, uncertainty penalties, ensembles, and diverse data reduce—but do not eliminate—this risk.

Retrieval: Receding-horizon control executes only the first action so it can observe reality again.
