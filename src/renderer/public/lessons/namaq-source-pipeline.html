Commands

npm run history:validate -- data/history/batches/<batch>   # structure, anchors, provenance
npm run history:import   -- data/history/batches/<batch>   # dry run: prints the plan
npm run history:import   -- <batch> --apply                # writes; needs the approved revision
npm run history:review   -- <batch> --apply                # sets reviewStatus; separate gate
npm run catalog:ledger   -- --batch <batch>                # legacy values the batch walked past
Two gates, neither implying the other. Publishing records the current revision in batch.json, which is what lets --apply write. Marking reviewed sets each claim's reviewStatus and needs the user to say so explicitly. A published batch whose claims are all NOT_REVIEWED is a normal state (ADR 0008).

Rules that decide what may exist

A claim must back a value the model holds

A profile field, a title, a participation, an event link, or a person relation — otherwise history:validate rejects it. The pages already preserve the text, so a claim naming nothing is a second copy of it.

The files are authority; a row is a copy

ADR 0010. Never edit the database; edit the files and re-import.

Evidence role lives on the citation, not the work

ADR 0011. Shamela is a delivery host, not an evidence class — which is also why it is never the thing a citation rests on.

One citation is one meaningful selection

Page turns, paragraph boundaries and footnote placement do not create citations. Join fragments, use a page range across printed pages, ellipse omitted text.

A multi-volume source needs volumeNumber

Set on the account (or on a page, where an entry crosses a binding). Nothing infers it, and a batch missing it still validates clean — the entry just files under "no assigned volume".

The seam to remember

An anchor is paired to its paragraph by position, not by any marker in the markdown: passageExcerpts in src/lib/history/batchSchema.ts splits the body on blank lines and zips the list. Insert a paragraph mid-page and every later anchor now excerpts different text. See lesson 0001.
